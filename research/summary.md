## Method and honesty note (read first)

Instagram could not be inspected from this session: the cloud environment's network blocks instagram.com (and Agent Reach's Instagram channel requires a logged-in desktop Chrome, which a cloud container does not have). **No post media or paid-partnership labels were verified first-hand.** Every claim below rests on cited web sources: press releases, trade press (Marketing Brew, Front Office Sports, Tubefilter, Campaign), brand newsrooms, agency/booking pages, and creator-marketplace aggregators — with evidence strength labeled per row. Exact Instagram post URLs were not retrievable via indexed search for any collaboration; the CSV marks these "Not found — verify locally." A disclosure never proves a cash fee, and self-reported client lists are labeled as such. Run `research/local_verification_prompt.md` in a local desktop session to close these gaps.

Follower counts are indexed snapshots or aggregator figures with sources noted — not live reads. Creator base ≠ audience geography; Magnet's audience-country split remains unknown, so all geographic fit is provisional.

## Uncertainty labels used in the CSV

- **Strong** = dated primary source (brand newsroom, platform PR, reputable trade press, official schedule).
- **Medium** = first-party interview, brand-owned blog, or dated press older than the window.
- **Weak** = aggregator listings (Motion, CreatorDB, Favikon), self-reported client lists, agency booking pages.
- "May be stale" on contacts = evidence older than ~18 months; verify before CRM entry. No email addresses were guessed anywhere.
- Older evidence (2016–2020 collabs) is included only where it shows a precedent and is explicitly dated.
